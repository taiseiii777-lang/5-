# セキュリティトレンド・デスク — 企画まとめ

grill-me で整理した内容（2026年5月）。実装状況は随時更新。

---

## 一言説明（発表・図解用）

業務に必要なセキュリティ・ガバナンス・業界ニュースを、4ペインで情報収集し、**業務への活かし方（AIコメント）** を見ながら **自分の示唆メモ** まで残す自分用画面。

---

## 背景・目的

| 項目 | 内容 |
|------|------|
| 想定業務 | 情報セキュリティ・プライバシーガバナンス（通信事業） |
| 担当領域 | ポリシー、ISO27001、インシデント、委託先、トレーニング、問い合わせなど |
| ツールの主目的 | **業務に必要な情報収集**（ニュース・トレンドのキャッチアップと業務への接続） |
| 今月の課題ゴール | 画面の**見た目**を仕上げる（データ保存・RSS連携は4ヶ月目） |
| 成功の定義 | ブラウザで動く見た目 ＋ **自分の言葉で何の画面か説明できる** |

---

## ツール名

**セキュリティトレンド・デスク**

---

## キャッチアップの対象範囲

以下の3つ（grill-me で A〜C と合意）。

1. **セキュリティ全般** — 脆弱性、インシデント事例、脅威トレンド など
2. **ガバナンス・規制** — ISMS/ISO27001、プライバシー、AIガバナンス、国内規制 など
3. **業界・通信** — 通信/MNO、グループ動向、競合・市場 など

※英語ソース専用（Englishnization 練習）は今回の主スコープ外。記事は日英混在で表現。

---

## 4ペイン構成

| ペイン | 位置 | 役割 |
|--------|------|------|
| 1 | 左 | トピック / カテゴリツリー（3本柱＋小カテゴリ） |
| 2 | 中央左 | 記事一覧（検索・未読/重要度フィルタはヘッダー） |
| 3 | 中央右 | 記事本文・要約（ダミー） |
| 4 | 右 | **業務への活かし方（AIコメント）** ＋ **あなたの示唆メモ** |

### ペイン1：カテゴリ（3本柱）— 実装済み

| 本柱 | 小カテゴリ（確定） |
|------|-------------------|
| セキュリティ全般 | 脆弱性、インシデント事例、脅威トレンド |
| ガバナンス・規制 | ISMS / ISO、プライバシー、AIガバナンス |
| 業界・通信 | 通信 / MNO、グループ動向、市場・競合 |

### ペイン2：記事一覧 — 実装済み

- 未読ドット、見出し、ソース、日付、カテゴリ、**重要度（高/中/低）**
- ヘッダー：検索、タグ（すべて / 未読 / 重要度：高）

### ペイン3：記事詳細 — 実装済み

- ダミー本文・要約、「原文は英語」バッジ（該当記事のみ）

### ペイン4：業務への活かし方 — 実装済み

- **AIコメント**（記事選択で切り替え）
  - 業務タグ（ポリシー / インシデント / 認証 / 委託先 / 教育 / エグゼ）
  - 業務への影響
  - 活かし方・意識すること
- **あなたの示唆メモ**（React state・セッション内のみ）
- データ：`src/data/article-ai-comments.ts`
